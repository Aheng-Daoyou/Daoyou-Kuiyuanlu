## 一、大陆骨架（山水总纲）

烬洲是一片**被渊从四面蚕食**的大陆。灯照所及的文明圈蜷缩在大陆东南，越往西北越荒、越暗、越接近渊。

- **北缘**：一道巨渊横贯北方天际（渊裂带），最深的黑段是九禁「无昼渊」；渊下一座倒悬塔即「倒悬观星台」。渊北是残雪荒原。
- **西北**：幽暗山地（幽都地界），亡者之城的山腹城门开在绝壁上（忘川渡），山麓坡地是鬼市。
- **西与西南**：灯外海。海是渊的领地，群岛与旧纪元遗物散落海面。
- **中**：古道战场丘陵（雍州），一条纵贯南北的古道北起班底庄、南至万骨驿，南端接出海口灯塔港。
- **东**：东部水网泽国（泽州），北缘巨渊的东端在天裂口收束。
- **东南**：京畿平原，灯照最密、坊市最盛；环形巨城烛京是天下最大灯。
- **南偏东**：雾瘴丛林（南疆），白莲乳母教的莲灯在雾里终年不熄。

**两条贯穿线**：
1. **古道（雍州脊线）**：班底庄 → 长平旧道（碑林牌坊）→ 万骨驿 → 灯塔港（出海口）。昔日战场沿路绵延。
2. **渊脉（渊的裂线）**：北缘巨渊（无昼渊、倒悬观星台）→ 西北忘川渡 → 西海天翁井 → 长夜古道。这不是路，是旧纪元撕开的一道裂缝，自北向南没入外海，越往南越接近「渊的尽头」。

**海路**：灯塔港是唯一大港，海路连通退潮屿、万灯楼（雾中浮影）、天翁井（孤岛巨井）与南疆雾泽。

## 四、连路（定稿，全双向）

几何原则：跨区通路一律沿「古道脊线」「渊脉裂线」「海岸线」三线走。

```text
京畿内网   烛京 ↔ 灰巷 / 灯草集 / 天枢峰 / 烟波泽 / 万骨驿
泽州内网   天枢峰 ↔ 灯草集；烟波泽 ↔ 灯草集；烟波泽 ↔ 天裂口
雍州古道   班底庄 ↔ 长平旧道 ↔ 万骨驿；班底庄 ↔ 观星台
北荒       观星台 ↔ 无昼渊
渊脉裂线   无昼渊 ↔ 忘川渡 ↔ 天翁井 ↔ 长夜古道
幽都       忘川渡 ↔ 鬼市（城与外围市集）
幽都↔海   鬼市 ↔ 灯塔港；鬼市 ↔ 万灯楼
灯外海     灯塔港 ↔ 退潮屿 / 万灯楼 / 万骨驿 / 三十七家村
南疆内网   三十七家村 ↔ 乳母腹地
```

**相对上游原版的连路修复（V1 已完成，V2 沿用）**：修复 4 处单向路；移除纵贯全图的长线，南疆改海路进入；新增忘川渡 ↔ 鬼市、长平旧道 ↔ 万骨驿。
