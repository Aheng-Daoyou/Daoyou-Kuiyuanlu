## 一、大陆骨架（山水总纲）

烬洲是一片**被渊从四面蚕食**的大陆。灯照所及的文明圈蜷缩在大陆东南，越往西北越荒、越暗、越接近渊。

- **北**：雪原与荒原（北荒），天光稀薄，九禁「无昼渊」「倒悬观星台」在此。
- **西北**：幽暗山地（幽都地界），亡者之城藏在山腹地下，忘川水从山根流出。
- **西与西南**：灯外海。海是渊的领地，群岛与旧纪元遗物散落海面。
- **中**：古道战场丘陵（雍州），一条纵贯南北的古道北起班底庄、南至万骨驿出海口。
- **东**：东部高地（泽州北缘），旧裂口「天裂口」悬在高原上。
- **东南**：水乡河网（泽州）与京畿平原，灯照最密、坊市最盛。
- **南**：雾瘴丛林（南疆），白莲乳母教的莲灯在雾里终年不熄。

**两条贯穿线**：
1. **古道（雍州脊线）**：班底庄 → 长平旧道 → 万骨驿（出海口）。昔日战场沿路绵延，碑林、古灯道井、腌物残渣都在这条线上。
2. **渊脉（西方裂线）**：无昼渊 → 忘川渡 → 天翁井 → 长夜古道。这不是路，是旧纪元在世界西缘撕开的一道裂缝，越往南越接近「渊的尽头」。

**海路**：灯塔港是唯一大港，沿海岸线西通鬼市滩涂、南抵南疆雾泽，海上散布退潮屿、万灯楼（雾中浮影）、天翁井（孤岛巨井）。

## 四、连路（定稿，全双向）

几何原则：不再有纵贯全图的长线；跨区通路一律沿「古道脊线」「渊脉裂线」「海岸线」三线走。

```text
京畿内网   烛京 ↔ 灰巷 / 灯草集 / 天枢峰 / 烟波泽 / 万骨驿
泽州内网   天枢峰 ↔ 灯草集；烟波泽 ↔ 灯草集；烟波泽 ↔ 天裂口
雍州古道   班底庄 ↔ 长平旧道 ↔ 万骨驿；班底庄 ↔ 观星台
北荒       观星台 ↔ 无昼渊
渊脉裂线   无昼渊 ↔ 忘川渡 ↔ 天翁井 ↔ 长夜古道
幽都       忘川渡 ↔ 鬼市（城与外围市集）
幽都↔海   鬼市 ↔ 灯塔港；鬼市 ↔ 万灯楼
灯外海     灯塔港 ↔ 退潮屿 / 万灯楼 / 万骨驿 / 三十七家村
南疆内网   三十七家村 ↔ 乳母腹地
```

**相对旧版的连路变更（共 5 处，均为修复或顺应新地理）**：

## 六、底图制作规范（public/assets/map/kuiyuanlu-map.webp）

- **尺寸**：3056×2143（与画布一致），webp，单图 ≤ 1.5MB。
- **风格**：浅色宣纸水墨古地图，留白多、线描淡，**不得出现任何文字**（区域名由前端水印层叠加）。
- **明度**：整体浅色（配合浅色主题与深色墨字水印），渊/禁地可局部以淡墨晕染示意，不出现大面积深色块。
- **地貌对应**（坐标即画布百分比）：
  - 北带（y<20）：雪原荒原，(48,10) 倒悬崖壁，(36,16) 一道无光巨渊。

  - 东部高地（y 42-50）：(87,46) 一道斜劈的天幕裂口。
  - 东南（y 44-60）：河网水乡大泽 (78,52)，半山孤峰 (66,44)。
  - 京畿平原（y 58-72）：(84,64) 灯火城郭，(73,59) 圩集，(79,71) 巷弄。
  - 南方雾林（y 76-92）：雾带横亘 (42-52,80-88)。
  - 西北山地（x 8-28, y 40-62）：幽暗山腹 (14,48)，山麓滩涂 (26,58)。
  - 西南大海（x<40 或 y>78 以西海域）：群岛 (30,73)、雾中楼影 (34,68)、孤岛巨井 (12,80)、海角古道 (7,91)；南海岸双港 (63,84)、(86,76)。
