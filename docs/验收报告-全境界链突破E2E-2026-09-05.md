## 四、发现并修复的真实缺陷

**问题**：角色突破进「掌灯」境界时落库 500。根因是数据库 CHECK 约束 `cultivators_mvp_realm_check` 的境界白名单漏了 **掌灯**（约束列了 闻腥/守灯/窥渊/蚀体/忘川/执灯/近神/渡渊，唯独漏掉 执灯 与 近神 之间的 掌灯）。该约束为早期手加到库、不在任何版本化迁移文件中。

**处置**：
1. 直接修复当前库：`ALTER TABLE ... DROP CONSTRAINT` + 重建（补入掌灯），已验证能写入 realm='掌灯'。
2. 补版本化可回滚迁移：
   - `drizzle/0039_realm_check_include_zhangdeng.sql`（幂等 drop+重建，含回滚说明）
   - `drizzle/meta/_journal.json` 追加 idx=39 记录
   - `drizzle/meta/0039_snapshot.json`（快照，表结构与 0038 一致）

## 五、测试手法经验（供后续复用）

- 大境界突破是**概率 roll**：高境界 chance 约 0.4~0.55（近神→渡渊 0.42、执灯→掌灯 0.56），**失败会消耗破境辅助状态 + 修为**，任务随之回 active、再次被门拦截——这符合"真实玩家冲关失败需重新准备（再次服香/补资源）"的设计，**非缺陷**。重试前必须重新补齐前置。
- 每次尝试前需重新注入 破境状态(statuses)/修为/窥悟；窥悟设到阈值+50；功法升至地品（满足一切 ≥玄品 要求）。
- 灯油(qi) 上限 QI_MAX=200 / QI_OVERFLOW_MAX=300，GM 补到 300 即可，勿重复大额补（会 409"已达溢出上限"）；gm grant 事务内 qi 失败仍会提交 cultivationExp。
