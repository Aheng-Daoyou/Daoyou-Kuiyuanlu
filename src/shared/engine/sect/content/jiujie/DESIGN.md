# 九劫天宫设计稿

> 本稿是九劫天宫的第二版收敛设计。目标不是继续增加独立规则，而是把“行为触发型雷罚”压缩成现有宗门体系可以承载的：一套共通资源、一套共通技能底板、两条在同一底板上改变触发来源与兑现方式的道途。精确倍率、费用、冷却、持续时间和节点数值最终以 TypeScript 定义与专项测试为准。

## 1. 宗门身份

- 正式名称：九劫天宫
- 简称：天宫
- 建议稳定内容 ID：`jiujie`
- 属性主题：雷
- 宗门气质：正统、肃穆、冷峻的天道审判道统
- 道途一：劫眼临身
- 道途二：天谴加身
- 共通战斗资源：劫数
- 共通核心状态：劫雷、劫债
- 核心战斗形态：不可驱散的行为型 DOT 与延迟清算

天宫不是传统的雷法爆发宗门。它以雷记录行为，以劫雷惩罚行动，以劫债等待清算。目标不是因为时间流逝而受伤，而是因为在身负天罚时继续施法、攻击或进行其他主动行为而触发雷罚。

核心循环：

```text
施加劫雷 → 目标主动行动 → 劫雷触发 → 获得劫数 / 增加劫债 → 消耗劫数清算
```

两条道途不拥有两套互不相干的资源和技能，而是共享同一循环：

- 劫眼临身：更多通过自身承伤获得劫数，再把承受的灾厄归还。
- 天谴加身：更多通过敌人行动触发劫雷获得劫数，再把目标的劫债提前兑现。

## 2. 背景设定

天地初开，九重天门悬于雷海之上。天劫并非单纯的突破试炼，而是天地对修士行为留下的回应：夺取机缘、逆转生死、强行续命和逃避代价，都会在天道中留下记录。

上古修士曾建立九劫天宫，试图整理这些记录。他们不自称天道，也不判断一个人是否“善”或“恶”，只记录：

- 谁引来了劫；
- 谁承受了劫；
- 谁试图逃避劫；
- 谁在劫临身时仍然选择出手。

因此，天宫的雷法更接近一套严苛的天道律令，而不是情绪化的惩罚。

天宫山门最高处有九座封闭天门。门中无人知道第九门后是什么，只知道历代宫主继任时都必须接受“九门问劫”。通过者可以执掌劫簿；失败者会化为雷池边的黑金石碑，继续记录后来者的脚步。

### 宗门教义

> 雷不因怒而落，劫不因弱而来。凡有所行，皆有天听；凡有所取，皆有归处。

### 门人誓言

> 我不求无劫，只求劫有所归。

### 叙事边界

第一版不确定开山祖师的姓名、年代和最终真相。宗门背景只承担三个功能：

1. 解释天宫为何记录行为；
2. 解释劫雷为何不可被普通驱散；
3. 为后续九重天门、宫主试炼和宗门剧情留下空间。

## 3. 共通战斗设计

### 3.1 共通资源：劫数

两条道途共用唯一战斗资源：**劫数**。

| 项目 | 设计 |
| --- | --- |
| 资源名称 | 劫数 |
| 资源性质 | 战斗内临时资源 |
| 建议上限 | 3 |
| 主要用途 | 强化或启动共通清算技能 |
| 获取方式 | 劫雷触发、承受直接伤害、部分节点奖励 |
| 消耗方式 | 共通清算技能和部分防御技能 |
| 两条道途差异 | 只改变获取倾向与消耗后的附加效果，不改变资源 ID |

劫数不是怒气、法力或第二条伤害条。它表示“天宫弟子当前手中握有多少可以调用的劫威”。

共通规则：

- 劫数不能超过上限。
- 溢出的劫数不转化为伤害，除非具体节点明确规定。
- 劫数不跨战斗保存。
- 劫数不直接造成回合伤害。
- 不为两条道途额外建立“应劫值”和“主罪值”两条独立资源。

道途差异：

- 劫眼临身：自身受到直接伤害时，更稳定地获得劫数。
- 天谴加身：敌方身负劫雷并主动行动时，更稳定地获得劫数。
- 两条道途都可以通过共通技能消耗劫数。
- 劫眼临身的节点倾向“消耗后承灾反击”，天谴加身的节点倾向“消耗后加速目标清算”。

### 3.2 共通状态：劫雷

劫雷是天宫最核心的持续状态。

建议将劫雷设计为一个有限层数、不可驱散的 Buff，而不是一个新的通用伤害类别。

基础规则：

- 劫雷由天宫技能施加。
- 劫雷不可被普通驱散、净化或移除效果清除。
- 劫雷持续若干回合，具体持续时间由技能和心法成长里程碑提供。
- 被标记目标成功进入一次主动行动阶段时，劫雷触发一次。
- 一次主动行动最多触发一次来自同一劫雷状态的结算。
- 触发造成雷属性持续伤害，并增加一层劫债或推进现有劫债。
- 劫雷造成的伤害不再次触发劫雷。
- 被动效果、DOT 结算、反应伤害、状态自然过期不视为主动行动。
- 劫雷自然结束时，不返还完整状态；只有特定节点可以把它转为一层较弱余劫。

“不可驱散”是劫雷的规则身份，不是驱散失败后额外反伤。第一版不设计“驱散反噬”，避免把反制交互扩展成第三套机制。

### 3.3 共通状态：劫债

劫债是劫雷触发后留下的可见计数。

基础规则：

- 劫雷每次有效触发时增加劫债。
- 劫债有明确上限，不允许无限叠层。
- 达到清算阈值时，不自动引入复杂控制，只为清算技能提供更高兑现价值。
- 共通终式可以消耗目标劫债进行一次天罚清算。
- 清算后劫债归零或按具体节点保留一层余债。
- 劫债不是劫雷的替代品：劫雷负责“目标行动时触发”，劫债负责“多次触发后的兑现”。

### 3.4 反制边界

为了保留对手决策，天宫不是“挂上就必死”。

对手可以：

- 暂停使用高价值主动技能；
- 使用普通攻击或低风险动作；
- 先击杀天宫弟子；
- 在劫债尚未达到阈值时调整战斗节奏；
- 通过防御、闪避或免伤降低劫雷本次实际收益。

对手不能：

- 用普通驱散移除劫雷；
- 通过清除一般 Buff 直接消除劫债；
- 用 DOT 结算触发劫雷；
- 让天宫因自身被动连锁产生无限劫雷。

## 4. 共通技能底板

两条道途共享以下基础神通。流派节点只改变这些技能的触发来源、目标范围、资源收益或清算偏向，不重新创建一套完全不同的技能列表。

| 技能 | 类型 | 职能 | 共通底板 |
| --- | --- | --- | --- |
| 《天听引雷》 | 基础神通 | 生成 | 对目标造成基础雷伤并施加劫雷；首次成功施加时建立天听记录 |
| 《承天受劫》 | 主动 | 防御 | 短暂降低受到的直接伤害；本次承受的部分伤害为后续天宫效果提供依据 |
| 《劫簿落印》 | 主动 | 标记 | 强化目标已有劫雷，或在目标尚无劫雷时补上一层；不直接清算 |
| 《雷狱问行》 | 主动 | 维持 | 延长劫雷或推进劫债；在目标已经行动过的情况下价值更高 |
| 《借劫回身》 | 主动 | 资源 | 消耗或转化部分劫数，获得短暂防御或强化下一次雷罚 |
| 《九霄清算》 | 主动 | 终式 | 消耗劫数，对带有劫雷或劫债的目标造成一次雷属性清算 |
| 《九劫天宫》 | 被动 | 宗门基础 | 提供劫雷、劫数和清算的共通底层规则，不直接决定流派方向 |

### 4.1 《天听引雷》

宗门默认生成技能。

基础行为：

1. 对单体造成低到中等雷属性伤害；
2. 对目标施加不可驱散劫雷；
3. 若目标已经有劫雷，则不重复创建同名状态，而是推进其持续时间或劫债准备；
4. 第一次成功施加后，为天宫弟子建立一次“天听”来源记录。

流派变体：

- 劫眼临身：对攻击劫眼的目标追加施加，或在自身承伤后强化下一次《天听引雷》。
- 天谴加身：对同一目标反复使用时，强化目标主罪行为带来的劫债推进。

### 4.2 《承天受劫》

共通防御技能。

基础行为：

- 施法者获得短暂直接伤害减免；
- 期间受到的直接伤害被记录为“本次承劫量”；
- 不产生无敌，不清除已有劫雷；
- 结束后本次承劫量只作为后续技能的动态标量来源，不自动造成反伤。

流派变体：

- 劫眼临身：承劫量更高比例转化为劫数或《九霄清算》的伤害。
- 天谴加身：承劫期间若敌人继续行动，强化敌方劫债推进，而不是强化自身承伤反击。

### 4.3 《劫簿落印》

共通标记技能。

基础行为：

- 对目标施加劫雷，或强化目标现有劫雷的持续时间；
- 若目标已有劫债，则优先推进清算准备；
- 不创建一套可无限叠加的罪名状态。

流派变体：

- 劫眼临身：优先标记最近攻击过自己的目标。
- 天谴加身：记录目标最近一次主动技能类型，作为“主罪”字段；主罪只保留一个，不扩展成多罪名系统。

### 4.4 《雷狱问行》

共通维持技能。

基础行为：

- 对带劫雷目标造成一次较弱雷伤；
- 延长劫雷剩余时间，或将即将过期的劫雷转为余劫；
- 如果目标本回合已经触发过劫雷，则额外推进一格劫债。

流派变体：

- 劫眼临身：对攻击过劫眼的目标提高伤害或追加劫数收益。
- 天谴加身：目标重复主罪行为后使用，直接推进劫债清算。

### 4.5 《借劫回身》

共通资源技能。

基础行为：

- 消耗 1 点劫数；
- 获得短暂防御性效果；
- 让下一次《天听引雷》《雷狱问行》或《九霄清算》获得明确强化；
- 不同时获得大量伤害、护盾和控制，避免一个技能包办全部职能。

流派变体：

- 劫眼临身：获得防御后，下一次承受直接伤害的一部分记录为待渡劫量。
- 天谴加身：获得防御后，下一次目标触发劫雷时额外推进劫债。

### 4.6 《因果回响》

共通追溯技能。

基础行为：

- 读取目标当前劫债或最近一次劫雷触发记录；
- 造成一次中等雷属性伤害，或把一部分已记录的劫债转为下一次清算增幅；
- 不消耗全部劫数，避免它与终式争夺唯一的清算位置；
- 劫雷不存在时不能凭空创造高额追溯伤害。

流派变体：

- 劫眼临身：读取本次承劫量，形成较弱的归劫伤害或防御回转。
- 天谴加身：读取目标主罪重复次数，强化下一次《九霄清算》的清算准备。

### 4.7 《九霄清算》

共通终式。

基础行为：

- 消耗 2 至 3 点劫数；
- 目标必须带有劫雷或劫债；
- 造成一次高额雷属性清算；
- 根据目标劫债数量提高伤害；
- 清算后按技能规则减少劫债，不直接清除不可驱散劫雷。

流派变体：

- 劫眼临身：伤害额外参考本场记录的承劫量，表达“将所受之劫归还”。
- 天谴加身：伤害额外参考目标重复主罪行为次数，表达“重罪加刑”。

## 5. 劫眼临身

### 道途定位

劫眼临身不是独立的反伤宗门，而是共通天宫底板的承灾偏向：

> 以身为劫眼，主动承受来力；把承受的灾厄转成劫数，再用共通清算归还。

它共享劫数、劫雷、劫债和全部共通技能。它不额外添加独立的“应劫资源”。

### 道途专属状态

只保留一个道途专属状态：**劫眼**。

- 劫眼是短时标记，不是永久形态。
- 劫眼期间，直接伤害记录为承劫量。
- 第一次攻击劫眼的敌人获得劫雷。
- 劫眼结束时，承劫量归入下一次共通技能的动态标量。
- 劫眼不能强制敌人攻击自己，避免变成传统嘲讽坦克。

### 六层节点主题

1. **开眼**：提高《承天受劫》的持续时间和第一次承劫收益。
2. **承灾**：承受直接伤害时获得少量劫数，设置每次行动或每回合上限。
3. **照身**：被劫眼标记的攻击者受到《雷狱问行》时伤害提高。
4. **闭目**：强化《借劫回身》的防御效果，并将部分承劫量保留到劫眼结束后。
5. **归劫**：强化《九霄清算》对承劫量的转化比例。
6. **劫后**：清算后获得短暂的劫后防御，但不重置全部资源、不形成循环免死。

### 劫眼流派战术

- **引敌入劫**：优先施加《劫簿落印》，再用《承天受劫》承接攻击。
- **闭目归劫**：在敌方爆发前使用防御，等待承劫量进入《九霄清算》。
- **先守后刑**：低血量时不追求继续加雷，先用《借劫回身》保命，再清算。

### 劫眼流派弱点

- 对不攻击自己的目标，劫数获取偏慢。
- 承劫量需要真实承受伤害，不是免费伤害记忆。
- 《九霄清算》前若被击败，积累的承劫量不会自动转为全额反击。
- 不拥有稳定嘲讽、永久减伤或传统反伤循环。

## 6. 天谴加身

### 道途定位

天谴加身不是另一套“罪名技能”，而是共通天宫底板的施罚偏向：

> 先用《劫簿落印》记录目标，再利用目标重复主动行为推进劫债，最后用《九霄清算》兑现。

它共享劫数、劫雷、劫债和全部共通技能。它不额外添加“主罪资源”；主罪只是劫簿上的一个有限记录字段。

### 道途专属记录

只保留一个道途专属记录：**主罪**。

- 主罪记录目标最近一次被天宫有效观察到的主动技能类别。
- 主罪不保存全部行为历史，只保存当前最值得惩罚的一类行为。
- 目标重复主罪行为时，劫雷触发额外推进劫债。
- 目标改变行为类型时，主罪不立即清除，但不继续获得重复加成。
- 目标死亡、主罪目标切换或清算后，按技能规则清除或重置。

### 六层节点主题

1. **记名**：强化《劫簿落印》的首次施加与主罪记录。
2. **问行**：目标重复主罪行为时，增加劫债推进。
3. **不赦**：劫雷即将过期时转为余劫，不允许目标用等待完全清除行为记录。
4. **重典**：强化《雷狱问行》对主罪目标的效果。
5. **天听**：目标触发劫雷后返还少量劫数，设置每回合上限。
6. **清册**：强化《九霄清算》对主罪重复次数的转化，但清算后清除主罪加成。

### 天谴流派战术

- **先记后罚**：先用《劫簿落印》确定目标，再用《天听引雷》建立劫雷。
- **诱其再犯**：目标重复主罪后，用《雷狱问行》推进劫债。
- **重罪清算**：保留劫数，等目标重复行为达到阈值后施放《九霄清算》。

### 天谴流派弱点

- 目标改变行为类型后，重复主罪收益下降。
- 对低频行动、普通攻击和纯被动构筑，劫债推进较慢。
- 天谴加身不能凭空强迫目标行动，也不因目标静止而造成高额伤害。
- 目标优先击杀天宫弟子，新的劫雷来源会立即停止。

## 7. 六本心法与基础数值加成

六本心法全部使用现有 `growthProfile` 和 `panelModifier` 体系。心法的面板收益必须落在已有 `AttributeType` 上，不新增“劫雷伤害”“劫债效率”之类无法归入基础战斗面板的专属属性。

每本心法仍然同时拥有：

- 一组伤害、治疗、护盾、状态效果成长；
- 一项符合自身设定的基础面板加成；
- 至少一门基础神通的来源。

| 心法 | 成长曲线 | 面板基础加成 | 设定理由 |
| --- | --- | --- | --- |
| 《九劫天书》 | balanced | `MAGIC_ATK`，ADD | 雷法以神识引动天威，提升所有天宫主动雷法的基础法术攻击 |
| 《劫眼观世经》 | early | `MAX_HP`，ADD | 以身为劫眼，必须具备承受第一轮灾厄的肉身 |
| 《天谴录》 | balanced | `CONTROL_HIT`，FIXED | 天罚标记需要准确落在目标身上，不以纯伤害替代审判命中 |
| 《雷狱镇魂篇》 | late | `MAGIC_PENETRATION`，FIXED | 雷狱穿透护持与灵力屏障，强化雷法对法防目标的有效性 |
| 《因果问罪诀》 | balanced | `MAX_MP`，ADD | 记录因果、维持劫雷和执行清算都需要稳定的法力储备 |
| 《渡劫归真法》 | early | `MAGIC_DEF`，ADD | 渡劫不是只会降雷，也要求门人拥有在天罚后继续站立的法身 |

说明：

- 以上均为面板基础数值加成，不把宗门专属机制伪装成属性。
- `CONTROL_HIT` 使用现有固定型面板修改器；其作用是提高劫雷、劫簿等带状态效果的命中稳定性。
- 具体满级上限应参考其他宗门的同类面板加成，不在设计稿阶段堆叠额外倍率。
- 不使用 `STRENGTH`、物理攻击或暴击作为天宫主轴，避免雷法与近战爆发混淆。
- `MAX_HP`、`MAX_MP`、`MAGIC_ATK`、`MAGIC_DEF`、`CONTROL_HIT`、`MAGIC_PENETRATION` 都是现有属性，不扩展 battle-v5 属性枚举。

## 8. 基础神通与解锁底板

- 《劫簿落印》
- 其余槽位为空

## 9. 编译和 battle-v5 边界

### 内容编译期负责

- 将共通技能底板编译为完整的 `AbilityConfig`；
- 根据已选道途节点调整劫雷持续时间、劫数获取、劫债推进和清算标量；
- 为同一技能生成流派变体的展示事实；
- 保证四槽主动技能不可重复，并且只能装配已解锁能力。

### battle-v5 只负责

- 行动事件、技能费用、冷却、Buff 生命周期；
- 标签触发、计数器、伤害、延迟伤害、资源修改；
- 既有的不可驱散 Buff 行为；
- 统一伤害管道和效果预算。

### 第一版不扩展

- 不增加 `jiujie` 专属 battle-v5 事件；
- 不增加九种劫数枚举；
- 不增加所有技能类别的永久历史记录；
- 不增加静止强制伤害；
- 不增加复杂多罪名并行状态；
- 不在通用层根据宗门 ID 分派逻辑。

若“成功进入主动行动阶段”不能由现有监听精确区分，则以现有 `ActionPreEvent` 的稳定语义作为第一版边界，并通过共享引擎的通用测试锁定：同一动作最多触发一次、DOT 不触发、被动不触发、不可驱散状态不被普通清除效果移除。

## 11. 视觉和文案基准

### 视觉

- 主色：深夜蓝、青白雷光、暗紫、炭黑、克制旧金。
- 建筑：悬浮残宫、断裂天柱、黑金宫墙、雷链、半毁天门。
- 劫眼临身：暗紫、焦黑、圆形祭坛、巨眼雷纹。
- 天谴加身：冷白、黑金、雷简、垂直天罚光柱。
- 整体：庄严、秩序化、具有天道官署感，不表现为邪异雷魔。

### 文案

技能描述按以下顺序书写：

1. 先说明天宫弟子做了什么；
2. 再说明目标身上的劫雷或劫债如何变化；
3. 最后说明消耗、清算或流派节点带来的差异。

避免：

- “目标所有行为均受惩罚”这类绝对描述；
- 把劫雷写成普通毒、灼烧或流血；
- 把劫眼写成永久嘲讽或无条件反伤；
- 把天谴写成完整的罪名数据库；
- 用宗门专属名词替代实际战斗效果。

## 13. 待实现前的确认点

- 共通资源 ID 采用“劫数”还是更具法术感的“劫炁”；本稿暂用“劫数”。
- 劫雷的单次触发使用 `ActionPreEvent` 还是现有监听链中更晚的稳定事件，需要以 battle-v5 行动生命周期核对。
- 劫雷不可驱散是否能直接复用现有 Buff 标志；若不能，只增加通用的不可驱散能力，不增加天宫专属规则。
- 主罪字段是否能通过现有运行时计数器和 marker 表达；若不能，第一版暂不保存行为类别，只保留“重复触发次数”。
